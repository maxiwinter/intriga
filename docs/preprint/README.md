# Preprint — artefactos históricos

Todo lo que hay en este directorio (`preprint-v0-1.md` … `preprint-v0-6.md`, sus
`CHANGELOG-*`, sus `VALIDATION-REPORT-*`, `notas-auditoria-impacto-originalidad.md`,
`reproduccion-2026-08-26.md`) es **anterior al snapshot del 27 de agosto de 2026**.

Se conservan bajo la convención del proyecto — un archivo por versión, nada se reescribe
silenciosamente — para que el recorrido y sus correcciones queden auditables. **No describen
el estado actual del proyecto.**

## Cómo leer las afirmaciones de estado que contienen

Varios de estos archivos dicen, correctamente para su momento, cosas como:

- *"Prepared for freezing — NOT YET FROZEN OR PREREGISTERED"*
- *"consolidated and prepared for freezing but not yet frozen and not publicly preregistered"*
- *"Neither freezing nor public preregistration has taken place at the time of writing"*

**Eran verdaderas cuando se escribieron y describen ese momento, no el estado vigente.** El
protocolo v1.1 fue congelado el **2026-08-27** y preregistrado públicamente ese mismo día en
OSF — **https://osf.io/yq9hr**. Esas frases no se corrigieron aquí porque corregirlas
retroactivamente destruiría precisamente lo que estos documentos preservan.

Ninguna de ellas sigue siendo cierta: tanto el congelamiento como el depósito público están
consumados, y la v1.1 **puede** citarse hoy como pre-registro público. Léanse como registro
del recorrido, no como estado.

artefacto congelado, y puede seguir cambiando.
