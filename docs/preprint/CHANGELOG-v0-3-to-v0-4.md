# Changelog del preprint — v0.3 → v0.4

**Fecha:** 2026-08-26. **Archivo nuevo:** `preprint-v0-4.md`. **Conservados sin modificar:** `preprint-v0-3.md`, `preprint-v0-1.md` (v0.2), `CHANGELOG-v0-2-to-v0-3.md`, `VALIDATION-REPORT-v0-3.md`.

**Naturaleza de esta revisión.** Correcciones **formales, de nomenclatura y de diseño experimental**. Ningún experimento empírico se ejecutó; ningún dataset se abrió; ninguna cifra se inventó ni se recalculó a mano. Se agregó **un** script versionado (`src/g_metricas_oos.py`) que imprime una métrica que antes estaba derivada, sin modificar ningún script ni salida previos. Cada cambio que altera cómo debe leerse un número existente se declara expresamente abajo.
